# Student Performance Predictor

## 📌 Project Description
This project predicts student marks based on the number of study hours using a simple Machine Learning model. It helps students understand how study time affects academic performance.

## 🎯 Problem Statement
Many students are unsure how much studying is needed to achieve better marks. This project aims to provide a basic prediction based on study hours.

## 🧠 Solution
A Linear Regression model is used to predict marks based on study hours using a dataset.

## 🛠️ Technologies Used
- Python
- Pandas
- Scikit-learn

## 📊 Dataset
The dataset contains two columns:
- Study Hours
- Marks

## ▶️ How to Run
1. Install required libraries:
   pip install pandas scikit-learn

2. Run the program:
   python model.py

3. Enter study hours when asked.

## 📈 Output
The program predicts marks based on the input study hours.
